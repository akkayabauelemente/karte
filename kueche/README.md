# Küchen-Timer-Listen

Diese Textdateien speisen die NFC-Timer auf dem iPhone.
Ein NFC-Sticker je Gerät → Kurzbefehl holt die zugehörige Datei → Menü → Timer läuft.

**Erweitern:** eine Zeile ergänzen. Format ist frei lesbar, entscheidend ist nur,
dass **genau eine Zahl** in der Zeile steht — die wird als Minuten gelesen.

    Lasagne — 45 Min

**Neues Gerät:** neue Datei anlegen + neuen Kurzbefehl nach demselben Muster.
Nichts Bestehendes muss angefasst werden.

Abrufbar unter `https://karte.akkaya-bauelemente.de/kueche/<gerät>.txt`
