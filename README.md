# karte.akkaya-bauelemente.de

Digitale Visitenkarten hinter den NFC-Karten und QR-Codes.

**Warum ein eigenes, oeffentliches Repo:** Auf dem NFC-Chip und dem
aufgedruckten QR steht nur die *Adresse*, nie der Inhalt. Der Inhalt lebt
hier und kann jederzeit geaendert werden, ohne dass eine Karte neu gedruckt
oder ein Chip neu beschrieben werden muss.

**Was hier NICHT hingehoert:** nichts aus der Kommandozentrale. Keine
EK-Preise, keine Lieferantennamen, keine Kundendaten. Nur das, was ohnehin
auf einer Visitenkarte steht.

## Adressen

| Pfad | Inhalt |
|---|---|
| `/ilhami/` | Ilhami Akkaya |
| `/` | leitet vorerst auf `/ilhami/` |
